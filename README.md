# Muhammed Salim K T: portfolio

Static personal site: production voice AI (Echo), multi-agent engine, RAG at 10M+ embeddings, Arabic LLM work.

- `index.html`: the whole site (no build step)
- `assets/`: diagrams and CV
- `render.yaml`: Render static-site blueprint

Deploy: [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/salimkt/salim-portfolio)

Note: the Render service was created from the public repo URL, so pushes don't auto-deploy. After pushing, open the Render service `muhammed-salim` and click Manual Deploy → Deploy latest commit (or connect the GitHub app in Render for auto-deploys).
